# Responsive Navigation Menu

Extract the ZIP and open `index.html` in your browser. You don't need to install anything.

- On desktop, use the links in the header.
- Below 760px, the links move into the hamburger menu.
- Select a link, press Escape, use the close button, or click outside to close the drawer.

## Project files

- `index.html` has the navigation and the four page sections.
- `styles.css` handles layout, the media query, and the hover and drawer transitions.
- `script.js` opens and closes the drawer and highlights the selected link. When you select a link in the drawer, focus moves to that section.

To rename or add a section, keep its ID and the matching links in both menus in sync.
